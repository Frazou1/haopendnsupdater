# HA OpenDNS Updater

**FR** — Garde à jour l'adresse IP publique de votre réseau OpenDNS (seulement quand elle change, plus une fois par jour), pour que le filtrage OpenDNS continue de s'appliquer quand votre fournisseur Internet change votre IP. Le résultat est publié dans Home Assistant par un capteur MQTT. Voir l'onglet **Documentation** ou la [documentation complète](https://github.com/Frazou1/haopendnsupdater/blob/main/haopendnsupdater/DOCS.md).

**EN** — Keeps your OpenDNS network's public IP address up to date (only when it changes, plus once a day), so OpenDNS filtering keeps applying when your ISP changes your IP. The result is published to Home Assistant as an MQTT sensor. See the **Documentation** tab or the [full documentation](https://github.com/Frazou1/haopendnsupdater/blob/main/haopendnsupdater/DOCS.md).
